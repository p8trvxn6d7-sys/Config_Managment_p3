# Ассемблер и интерпретатор УВМ (вариант 31)

Практическая работа № 3 по дисциплине «Конфигурационное управление»
(ИКБО-41-25, РТУ МИРЭА). Язык реализации — Python 3.8+, сторонние
библиотеки не нужны.

## 1. Общее описание

Проект — ассемблер и (в следующих этапах) интерпретатор для учебной
виртуальной машины (УВМ). Ассемблер читает текст программы на
«алгебраическом» языке, похожем на язык высокого уровня, и преобразует его
в промежуточное представление: список команд, в котором каждая команда
задана полями `A`, `B`, `C` и их значениями.

Статус этапов:

| Этап | Содержание | Статус |
|------|------------|--------|
| 1 | Перевод программы в промежуточное представление | выполнен |
| 2 | Формирование машинного кода | — |
| 3 | Интерпретатор и операции с памятью | — |
| 4 | АЛУ (команда `abs()`) | — |
| 5 | Тестовая задача | — |

## 2. Описание языка и настроек

### 2.1. Команды УВМ

Все команды начинаются с поля `A` (биты 0–7) — кода операции.
Номер регистра — 6 бит (0–63), константа и адрес — 31 бит
(0 … 2 147 483 647).

| Команда | Запись на ассемблере | A | B | C | Размер |
|---------|----------------------|---|---|---|--------|
| Загрузка константы | `rB = C` | 140 | биты 8–13, регистр | биты 14–44, константа | 6 байт |
| Чтение из памяти | `rB = mem[C]` | 21 | биты 8–13, регистр | биты 14–44, адрес | 6 байт |
| Запись в память | `mem[C] = rB` | 171 | биты 8–13, регистр | биты 14–44, адрес | 6 байт |
| Унарная операция `abs()` | `mem[rC] = abs(rB)` | 146 | биты 8–13, регистр | биты 14–19, регистр | 3 байта |

Семантика:

- `rB = C` — записать константу `C` в регистр `B`;
- `rB = mem[C]` — записать в регистр `B` значение из памяти по адресу `C`;
- `mem[C] = rB` — записать значение регистра `B` в память по адресу `C`;
- `mem[rC] = abs(rB)` — вычислить модуль значения регистра `B` и записать
  в память по адресу, который лежит в регистре `C`.

### 2.2. Синтаксис

- Одна команда на строку.
- Регистры: `r0` … `r63`.
- Числа: десятичные (`374`), шестнадцатеричные (`0x176`), двоичные
  (`0b101110110`). Отрицательные числа не поддерживаются.
- Комментарий начинается с `#` и идёт до конца строки.
- Пустые строки игнорируются; регистр букв и пробелы вокруг `=`, `[`, `]`,
  `(`, `)` значения не имеют.

Пример (`examples/spec_tests.asm`) — команды из тестов спецификации:

```
# Тестовые команды из спецификации УВМ (вариант 31)
r54 = 374            # LOAD:  A=140, B=54, C=374
r9 = mem[514]        # READ:  A=21,  B=9,  C=514
mem[737] = r54       # WRITE: A=171, B=54, C=737
mem[r54] = abs(r9)   # ABS:   A=146, B=9,  C=54
```

### 2.3. Ошибки

Ошибка трансляции выводится в `stderr` с номером строки, код завершения — 1:

```
Ошибка: строка 1: значение 64 не помещается в поле B (6 бит, максимум 63)
Ошибка: строка 2: неизвестная команда или ошибка синтаксиса: 'bad line'
```

### 2.4. Аргументы командной строки

```
python -m uvm <source> <output> [--test]
```

| Аргумент | Назначение |
|----------|------------|
| `source` | путь к исходному файлу с текстом программы |
| `output` | путь к двоичному файлу-результату (запись появится на этапе 2) |
| `-t`, `--test` | режим тестирования: вывести поля и значения команд |

На этапе 1 двоичный файл не формируется: без `--test` программа только
проверяет текст и сообщает об этом в `stderr`.

## 3. Сборка и тесты

Сборка не требуется. Нужны Python 3.8+ и `make` (необязательно).

```
make test    # запустить тесты (unittest)
make run     # ассемблировать examples/spec_tests.asm в режиме тестирования
make clean   # удалить build/ и __pycache__
```

Без `make`:

```
python3 -m unittest discover -s tests -t . -v
PYTHONPATH=src python3 -m uvm examples/spec_tests.asm out.bin --test
```

Тесты в `tests/`:

- `test_spec_examples.py` — тесты из спецификации: поля и значения команд
  совпадают с `A=140, B=54, C=374` и т. д.;
- `test_translator.py` — синтаксис, комментарии, системы счисления, границы
  полей, ошибки, согласованность таблицы синтаксиса со спецификацией;
- `test_cli.py` — режим `--test`, ошибки чтения и разбора.

## 4. Примеры использования

```
$ make run
python3 -m uvm examples/spec_tests.asm build/spec_tests.bin --test
A=140, B=54, C=374
A=21, B=9, C=514
A=171, B=54, C=737
A=146, B=9, C=54
```

Эти четыре строки идентичны тестам из спецификации УВМ:

| Команда | Тест из спецификации | Вывод ассемблера |
|---------|----------------------|------------------|
| загрузка константы | A=140, B=54, C=374 | `A=140, B=54, C=374` |
| чтение из памяти | A=21, B=9, C=514 | `A=21, B=9, C=514` |
| запись в память | A=171, B=54, C=737 | `A=171, B=54, C=737` |
| `abs()` | A=146, B=9, C=54 | `A=146, B=9, C=54` |
